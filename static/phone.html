USSD · AFRICA’S TALKING CALLBACK FORMAT

A farmer’s check-in on a basic phone

This phone sends the same form fields Africa’s Talking sends to a USSD callback: sessionId, serviceCode, phoneNumber and text. Fieldwise answers with CON to keep the menu open or END to close it. To go live, register /ussd as the callback URL for a USSD code in an Africa’s Talking account.

  • Farm numbers: 14, 27, 43, 56, 62, 75, 84 and 91.
  • The farmer agrees before any question. Saying no saves nothing.
  • The phone number is sent, as Africa’s Talking does, but Fieldwise never stores it.
